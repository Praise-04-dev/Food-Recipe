# 🍝 Food Recipe — Spaghetti with Meat Sauce

A responsive recipe page built with HTML and CSS, featuring an embedded video tutorial, ingredients list, step-by-step instructions, and serving notes — all laid out in a clean three-column grid.

## Preview

The page displays a classic Spaghetti with Meat Sauce recipe with:
- An embedded YouTube cooking video
- A full ingredients list
- Numbered cooking instructions
- A dish photo
- Recipe notes and substitution tips

## Project Structure

```
Food Recipe/
├── index.html
├── style.css
└── images/
    ├── Spaghetti.jpg
    └── background.jpg
```

## Built With

- HTML5
- CSS3 (Grid layout, custom styling)
- Google Fonts — [Pacifico](https://fonts.google.com/specimen/Pacifico) & [Allura](https://fonts.google.com/specimen/Allura)

## Features

- **Three-column CSS Grid** layout for video, recipe details, and image
- **Embedded YouTube video** for a visual cooking guide
- **Styled ingredients and instructions** sections with distinct card designs
- **Recipe notes** panel with substitution and storage tips
- **Background image** with fixed attachment for a food-magazine feel

## Getting Started

1. Clone or download the repository
2. Place your images inside an `images/` folder at the project root:
   - `Spaghetti.jpg` — the dish photo
   - `background.jpg` — the page background
3. Open `index.html` in your browser

> No build tools or dependencies required — it runs straight in the browser.
